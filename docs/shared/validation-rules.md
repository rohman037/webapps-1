# Shared Validation Rules

## 17-Point Clip Structure Rules (C1-C17)
1. **C1**: Keberadaan Hook Type metadata.
2. **C2**: Kelengkapan 7 field mandatory per klip (Visual, Aksi, Voice Over, Text Overlay, SEO Keyword, Trust Element, ProductionNote).
3. **C3**: 5-Stage Story Arc Progression (GOLDEN HOOK, PAIN POINT, SOLUTION DEMO, BENEFIT REINFORCEMENT, CALL TO ACTION).
4. **C4**: Konsistensi durasi timeline klip (start-end detik).
5. **C5**: Larangan background music (BGM/lagu/musik) dalam instruksi audio.
6. **C6**: Pembatasan maksimal 5 hashtag (non-spam, niche-specific).
7. **C7**: Perspektif persona kedua ("kamu") — anti-slop "kami/kita".
8. **C8**: Kejelasan instruksi framing visual & angle kamera.
9. **C9**: Instruksi pencahayaan realistis & volumetrik.
10. **C10**: Keberadaan caption teroptimasi SEO pencarian TikTok (Short & Long-tail search queries).
11. **C11**: Ketiadaan buzzword basi ("FYP", "racun tiktok", "terviral", "wajib punya").
12. **C12**: Visual anchor produk konsisten di seluruh segmen.
13. **C13**: Zero-hallucination fact check pada klaim produk.
14. **C14**: Batas waktu transisi per klip (2-4 detik per segment cut).
15. **C15**: Natural sound effects (SFX) kontekstual.
16. **C16**: Call To Action spesifik (keranjang kuning / bio / komentar).
17. **C17**: Schema formatting markdown utuh tanpa tag bocor.
